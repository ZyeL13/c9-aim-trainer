# Demo Video Shot List — C9 Aim Trainer

Target: **under 3 minutes**, public on YouTube. Record at 1080p, desktop
browser, mouse cursor visible. No copyrighted music — use the game's own
WebAudio sounds or silence.

## Shot 1 — Hook (0:00–0:15)
- Full start screen: title, "60 seconds. Targets appear — click them before
  they fade", the big START button.
- Voiceover / caption: "C9 Aim Trainer — a 60-second flick-shot game for the
  Cloud9 booth. Mouse only. No tutorial needed."
- Click START.

## Shot 2 — The core loop (0:15–1:00)
- 20–30 seconds of live play: targets spawning, fast clicks, floating
  "+245" score popups, combo counter climbing (×5, ×8…).
- Deliberately miss once (click empty space) to show the combo resetting —
  say so in the voiceover: "A miss breaks your combo."
- Show the HUD: timer counting down, score, hits/misses, accuracy updating.

## Shot 3 — The end screen + leaderboard (1:00–1:40)
- Timer hits zero. End screen appears: score, accuracy, best streak,
  average reaction time.
- Type a name, click **Save score**, show the entry appearing on the
  booth leaderboard (top 10, stored on the device).
- Caption: "Leaderboard is local — no Wi-Fi needed at the venue."

## Shot 4 — Booth reset (1:40–2:10)
- Click **Play again** — a new round starts instantly, HUD back to zero.
- End the round (or cut to the end screen) and click **Next player** —
  clean start screen, ready for the next fan.
- Caption: "Idle for 60 seconds and it resets itself — a walk-away never
  blocks the queue."

## Shot 5 — Why it fits + JetBrains (2:10–2:45)
- Quick pan over the repo in WebStorm (`.idea/` folder visible) and the
  README's JetBrains tooling section.
- Voiceover / caption: "Built in a WebStorm project, with AI assistance.
  Plain web code — no build step, no server, no network. Open index.html
  and it runs."
- Closing card: game title, category (Category 3 — Event Mini Game),
  hackathon name, repo link.

## Checklist before uploading
- [ ] Video < 3:00 (judges are not required to watch beyond 3 minutes)
- [ ] Public on YouTube, link pasted in the Devpost submission form
- [ ] Shows the game actually working, end to end — not slides
- [ ] No third-party trademarks, copyrighted music, or Riot assets visible
- [ ] Captions / voiceover in English
